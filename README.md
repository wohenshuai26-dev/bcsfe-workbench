# 貓咪存檔工作台

在瀏覽器裡用按鈕修改《貓咪大戰爭》存檔的本機工具。它是 [BCSFE（Battle Cats Save File Editor）](https://codeberg.org/fieryhenry/BCSFE-Python) 的視覺化介面：畫面上的每個按鈕，背後都是呼叫 BCSFE 本身的函式，所以下載、存檔和上傳的方式都跟 BCSFE 一樣。

> ⚠️ **使用前請先讀「風險」一節。** 修改存檔違反遊戲的使用條款，可能導致帳號被封鎖。使用本工具造成的任何後果由使用者自行負責。

## 功能

- **取得存檔**：輸入遊戲裡的引繼碼和認證碼，從伺服器下載；或載入電腦上已經下載過的存檔。
- **道具**：貓罐頭、XP、各種轉蛋券、NP、統率力，以及戰鬥道具、貓眼石、貓薄荷果實、維他命、寶箱，可以一項一項改。
- **貓咪**：解鎖遊戲中拿得到的貓、等級拉滿、第三和第四型態、本能、圖鑑；也能在「貓咪」頁搜尋、依稀有度篩選，再個別或整批改等級。
- **特殊能力**：研究力、貓咪砲、工作狂貓等能力的等級。
- **關卡**：主線全通關、寶物全金。
- **上傳**：上傳到伺服器並取得新的引繼碼，回手機引繼就能讀回來。
- **解除上限**（預設關閉）：打開後可以填超過遊戲上限的數值，畫面會變成黑底紅色的警告模式。

畫面語言是繁體中文，預設對應台灣版（tw），也支援日版、英文版、韓版的存檔下載。

## 需求

- macOS 或 Linux（Windows 可以手動執行，見下方）
- Python 3.9 以上（建議 3.12，macOS 可以用 Homebrew 安裝：`brew install python@3.12`）
- 網路連線（下載、上傳存檔，以及第一次下載遊戲資料時需要）

## 安裝與啟動

```bash
git clone <這個專案的網址>
cd bcsfe-workbench
./start.sh
```

`start.sh` 第一次執行時，會在專案資料夾裡建立 `.venv` 並安裝 BCSFE，接著啟動工作台。看到下面這行後，用瀏覽器打開網址：

```
貓咪大戰爭存檔編輯器已啟動：http://127.0.0.1:8765
```

要關閉工作台，在終端機按 `Ctrl+C`。

### 手動安裝（包含 Windows）

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt      # Windows：.venv\Scripts\pip install -r requirements.txt
.venv/bin/python server.py                      # Windows：.venv\Scripts\python server.py
```

### 設定

| 環境變數 | 預設值 | 用途 |
|---|---|---|
| `BCSFE_GUI_PORT` | `8765` | 工作台使用的連接埠 |
| `BCSFE_GUI_SAVE` | `~/.local/share/bcsfe/saves/SAVE_DATA` | 存檔位置（和 BCSFE 預設相同） |

## 使用流程

1. **在手機拿引繼碼**：遊戲裡「設定 → 資料引繼」，拿到引繼碼和認證碼後就不要再打開遊戲。每組碼只能用一次。
2. **下載存檔**：在工作台輸入兩組碼，選擇遊戲版本，按「下載存檔」。原始存檔會自動備份到 `~/.local/share/bcsfe/saves/transfer_backup`。
3. **修改**：在「總覽」、「道具」、「貓咪」三個頁面調整數值。
4. **上傳**：回「總覽」最下面，按「上傳並取得新引繼碼」。畫面會顯示**新的**引繼碼和認證碼，請馬上抄下來。
5. **回手機引繼**：遊戲標題畫面選「資料引繼」，輸入新的碼。

> 手機上已經引繼過之後，電腦上的存檔就是舊的。想再改一次，要從第 1 步重新開始。

## 風險

- **封號**：遊戲伺服器會檢查存檔，數值不合理（特別是貓罐頭和轉蛋券）就可能封號。「解除上限」產生的數值是正常玩不可能出現的，風險更高。
- **存檔損壞**：數值超出範圍可能讓遊戲顯示錯誤或閃退。出問題時，可以用 `transfer_backup` 裡的原始存檔還原。
- **引繼碼外洩**：引繼碼和認證碼等於帳號鑰匙，不要貼給任何人，截圖前記得遮掉。
- **使用條款**：修改存檔違反《貓咪大戰爭》的使用條款。本專案與 PONOS 無關，也沒有得到 PONOS 的授權或認可。

## 安全性與網路連線

- 工作台只監聽 `127.0.0.1`，同一個網路上的其他裝置連不進來。
- 會連到外部的地方只有這幾個：
  - **PONOS 官方存檔伺服器**：用引繼碼下載存檔、上傳存檔時。
  - **BCSFE 的遊戲資料來源**（git.battlecatsmodding.org）：第一次讀取貓咪名稱、道具名稱等遊戲資料時，由 BCSFE 下載。
  - **Google Fonts**：網頁字型，連不上時會改用系統字型。
- 只接受來自工作台自己網頁的修改請求。
- 終端機不會印出你輸入的引繼碼。
